# 折线图的品类对比与日期顺序

基础折线图的「子类别 / 维度」用于拆分系列。例如类别轴放取值时间、子类别放详细品类、值轴放业绩求和，就会按品类生成多条线，无需新增“对比字段”区域。

## 修复的问题

查询行可能按指标或品类排序。旧渲染逻辑使用日期第一次出现的顺序建立横轴，同时按各系列的输入顺序连线，导致日期乱序、折线横跨图面或来回折返。

现在单个日期类别轴在未配置钻取时，默认按日期升序绘制；明确的日期降序和自定义排序仍生效。普通分类轴保留原有类别顺序。所有系列按同一个横轴顺序连接，保留系列先后顺序、颜色配置、数值、空值以及提示和点击联动需要的字段信息。排序在空值策略执行后进行，补入的空值点也会正确排列，不修改原始查询数据。

本次仅涉及前端。无需重新编译 Java 后端；本地开发页面刷新即可加载，服务器部署仍需更新前端构建产物。

## 验收

- 取值时间 + 详细品类 + 业绩求和，多品类交错返回时日期从左至右有序。
- 日期降序、自定义顺序仍然有效。
- 基础折线图默认跨过空值，连接前后两个有效点；缺失值保持为空，不生成假数据点。开头、结尾没有有效点的区间不外推。
- “高级 → 空值处理”的默认选项显示为“跨空值连线”；原有图表的默认配置也直接采用这种连线方式。明确选择“置为0”时仍按零值绘制，其他图表的空值策略保持不变。
- 与其他平台对比时，另行核对日期范围、筛选、聚合方式和结果行数限制；排序不会恢复查询阶段已截断的数据。
