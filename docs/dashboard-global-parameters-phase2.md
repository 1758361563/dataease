# 仪表板全局参数：第二阶段实施记录

日期：2026-10-10。状态：第二阶段代码完成，核心计算及前端构建验证通过；尚未部署到运行服务。

## 功能与操作

仪表板编辑器顶部新增“全局参数与共享字段”入口，支持日期参数名称、固定日期/时间宏默认值及必填设置。配置应用后进入仪表板的保存与发布流程，修改会标记为未保存，并纳入既有撤销/恢复快照。参数当前选择值属于当前浏览会话，不写入共享定义。

同一入口可按数据集管理共享计算字段，设置维度/指标、结果类型和公式。卡片编辑器的字段区域新增“共享字段”入口，自动带入当前卡片的数据集。共享字段在同仪表板使用相同数据集的卡片中显示为同一字段，编辑这些字段时转到共享配置，不落入公共数据集或图表私有字段的保存接口。

公式支持用户提供的示例：

```text
if(and([取值时间]>=[DYNAMIC_PARAMS.期初],[取值时间]<=[DYNAMIC_PARAMS.期末]),1,0)
```

参数引用仍在服务端规范化为稳定 ID。图表私有计算字段的编辑器也列出当前仪表板参数，可引用共同参数及共享字段。

预览页面顶部显示参数日期控件。没有筛选器查询按钮时，改值立即生效并刷新卡片；存在查询按钮时，改值先进入草稿，点击现有筛选器查询按钮后，参数统一生效并刷新该仪表板卡片。清除操作恢复参数默认值，同样遵循有/无查询按钮的生效规则。参数栏会提示尚未查询的改动。

## 查询实现

- 新增 `POST /dataVisualization/calculationRuntime`，按 core/snapshot 版本读取定义，并用一次服务器时间基准解析默认日期；正式版本使用查看权限，编辑版本及定义覆盖使用编辑权限。
- 查询携带参数值与共同时间基准，编辑查询同时携带经过校验的当前定义。正式查询禁止请求覆盖已发布定义。字段枚举和下钻请求也携带该上下文。
- 服务端验证参数属于当前仪表板、必填和 ISO 日期格式。DATE 值生成受控的 `CAST('yyyy-MM-dd' AS DATE)`，缺省可选值生成 `CAST(NULL AS DATE)`。非法日期和额外参数在执行 SQL 前拒绝。
- 参数绑定发生在字段引用展开与 SQL 聚合之前；共享字段与私有字段复用现有公式编译链路。`if/and/or/not` 函数转换为 SQL 条件表达式，原公式的聚合位置保持不变。
- 共享指标已含聚合时继续使用现有聚合识别结果，刷新轴元数据并清除外层汇总，避免对 `SUM(...)` 再套一层 `SUM`。
- 筛选和下钻通过当前查询字段集合获取共享字段，不再要求它们存在于公共数据集字段表。
- 配置应用和最终保存均检查已有图表轴及私有字段的删除依赖；不可直接删除仍被使用的参数或共享字段。

日期参数按 DATE 类型绑定；数据字段自身的时间精度保持原定义。如果取值字段包含时分秒，要求按自然日比较时可在公式中明确使用 `CAST([取值时间] AS DATE)`。系统不会把所有数据字段自动截断到日期。

## 页面验收与第三阶段

部署时需应用第一阶段的 `V2.10.26__dashboard_calculation.sql`，更新前后端并重启服务。页面验收集中为三个操作：

1. 创建期初/期末参数与 YTD期间共享字段，确认同仪表板同数据集的两张卡片都可使用，另一个仪表板不出现该字段。
2. 修改日期，分别确认无查询按钮立即刷新、有查询按钮点击后刷新，并核对期间及已聚合业绩结果。
3. 保存、发布和重新打开，确认配置保留；在编辑器撤销配置改动，确认参数与字段恢复。

第三阶段接续复制 ID 重映射、模板/导入导出完整适配、缓存及业务迁移验收。当前参数查询接口已携带独立值快照，完整生命周期适配仍按第三阶段执行。
