# 透视表日期分组与格式

日期显示决定查询分组；日期格式仅决定表头文字。

- 年月：默认 `2026-07`，支持 `2026/07`、`7月`、`07`。隐藏年份时仍以完整年月分组，2025 年 7 月与 2026 年 7 月不会合并。跨年报表建议保留年份或增加年维度。
- 周（周一至周日）：查询键为周一日期，与格式无关。格式可选择 `2026年第42周` 或 `[2026-10-12, 2026-10-18]`。
- 年月日：日期格式可选择“星期名称（星期一）”。查询分组仍保留完整日期，不会把不同日期的星期一合并。
- 透视表的行/列维度支持重复拖入日期字段。每份字段有独立实例身份和格式；列维度依次放入两份同一日期字段，可分别显示“年度周次 + 周区间”或“日期 + 星期”。同一分组键的两层表头不会额外扩大日期范围或累计数值。
- 周次采用 ISO 周年：一年中包含首个星期四的周为第 1 周，所以 2025-12-29 至 2026-01-04 是 2026 年第 1 周。
- 原来保存的 `M` 月份配置保留原有“跨年按月号分组”行为；新建配置在年月格式菜单选择月份名称。

验证：前端日期格式与跨年边界测试、Vue 编译、ESLint；后端维度 SQL 编译与 MySQL 方言转换；本地 MySQL 只读验证周一/周日/下周一和跨年日期。其他数据库方言尚未实测。
