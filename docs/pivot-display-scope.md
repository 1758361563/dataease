# 透视表指标显示范围

在“数据列 / 指标”的指标菜单中选择“显示范围”：

- **所有列**：指标同时出现在日期明细和汇总区域，兼容原有配置。
- **仅汇总列**：指标只出现在左侧汇总区域，不生成各日期的明细列。选择后自动开启列总计并将其置于日期列前方。

例如：将“业绩”设置为“仅汇总列”，将“业绩占比”保留为“所有列”，即可同时展示累计业绩、累计占比和各月份占比。指标名称可以按需要改为“关联业绩”。

汇总遵循图表当前筛选范围。如果筛选了年初到昨天，业绩就是该区间的累计值；它不是一个忽略筛选的全年窗口计算字段。占比汇总继续使用原始数值和选定的计算范围重新计算，不直接累加各月份百分比。

此设置支持指标列头模式以及维度优先、指标优先两种表头顺序。指标行头模式下暂不应用该设置，菜单中会禁用“仅汇总列”。切回列头模式后恢复设置。

只调整展示，不删除查询指标；所有指标仍可参与汇总计算。Excel 导出使用相同的列布局及数值格式。

验证：`core/core-frontend/tests/pivotMeasureTotals.test.cjs` 使用实际 S2 层级、单元格查询及 Excel 导出覆盖混合显示、全部仅汇总、两种表头顺序和三种列宽模式。后端已验证打包 SDK 中字段的 JSON 往返保存及旧配置默认值。
