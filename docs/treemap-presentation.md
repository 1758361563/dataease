# 矩形树图的提示配置与交互

## 使用方式

- 数据面板新增“提示 / 字段”。点击指标字段菜单的“数值格式”，选择“数值”后可调整小数位；设为 0 即显示整数，也支持千分符、数量单位和后缀。
- 提示字段可调整名称、顺序、显隐，添加额外指标或删除字段。清空字段会关闭提示；额外指标继续使用已有查询流程，不增加分组维度。
- “样式 → 提示外观”保留文字颜色、背景颜色与字号，新增“显示占比”和“占比小数位”。占比按当前节点的父级合计计算，普通平铺矩形树图就是全图合计。提示占比与图内标签分开配置。
- 悬停时当前矩形突出，其他矩形淡化；离开节点或绘图区后恢复。原有点击联动仍使用原始维度、指标信息。

## 兼容与实现

旧图表无需重新创建，保留原来的数值格式、名称、颜色与查询配置；编辑提示字段后才保存为新版显式字段配置。旧图表尚未设置独立占比精度时，沿用已有标签精度；进入显式提示配置后默认两位，可单独修改。数值和占比分行展示；总额为零或无效时占比显示“—”。

饼图的紧凑提示外观提取为公共 `compactTooltip`，矩形树图复用同一套字号与间距。可见标题使用真实分类名称，正文至少 14px，容器随内容撑开并限制最大宽度。

绘图前复制查询结果，配色排序不再修改原始数组。G2 层级节点携带的维度、指标、额外提示值统一适配后交给已有提示字段渲染器。

本次只有前端修改，无需重新编译 Java 后端。

## 验证

`tests/treemapPresentation.test.cjs` 覆盖旧格式、新版字段顺序和格式覆盖、维度、额外指标、占比精度与关闭、清空提示、无效分母、绘制不修改查询结果、点击与悬停恢复。

`tests/piePresentation.test.cjs` 验证提取公共提示外观后饼图原有行为保持一致。真实页面检查了已有矩形树图的提示字段数值格式入口、独立占比设置、分类标题、紧凑提示及悬停淡化；未保存或发布仪表板。
