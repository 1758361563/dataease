# 本批透视表修改的部署说明

本批包含占比计算范围、周/星期与重复日期字段、指标优先多指标总计、总计列自适应以及指标“仅汇总列”。

部署需要同时更新：

- 前端资源：日期菜单、占比范围配置及 S2 表头和汇总展示。
- Java 后端及重新构建的 SDK：日期 SQL、占比计算和新增配置字段保存。

仅更新前端或使用旧 SDK 的后端可能导致新增设置不能保存或不能正确计算。服务器请沿用已有正式部署流程构建生产包；本地快速编译的 `CoreApplication-local.jar` 不作为包含生产前端资源的完整发布包。

本批透视表配置通过现有图表 JSON 保存，无新增数据库迁移；如果服务器落后于此前全局参数功能，仍需按该功能原部署说明完成已有迁移。

升级后建议抽查：

1. 同一日期两份列维度显示“日期 + 星期”或“周次 + 周区间”。
2. 指标优先下两个指标分别显示正确总计，切换三种列宽模式均正常。
3. 按渠道/年计算的占比与汇总正确，导出的 Excel 保留百分数格式。
4. “业绩”设为仅汇总列，“业绩占比”为所有列，保存并重新打开后设置仍保留。

飞书表格嵌入使用已有网页组件，本轮未增加外部文档接口或修改其权限。
