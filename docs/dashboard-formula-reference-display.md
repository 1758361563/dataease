# 共享公式中的字段名称

共享公式继续保存稳定的字段 ID，避免字段或日期参数改名后引用失效。配置抽屉现在将引用映射为名称，例如 `[1308143991480520706]-[1308143991480520707]` 显示为 `[MTD业绩]-[MTD同期业绩]`。

显示覆盖当前数据集的原始字段、当前仪表板共享字段和日期参数。原始字段名称在打开抽屉时加载；共享字段以抽屉里的最新名称为准。编辑公式及点击插入时将已知名称转换回 ID，未知引用保留交给既有后端校验；字符串和引号中的方括号不做替换。

该修改仅涉及前端，已有公式无须重新录入或迁移。测试 `dashboardFormulaReferences.test.cjs` 覆盖名称与 ID 往返、超大 ID、数据集隔离、字段/参数改名、字符串及缺失引用保护和 Vue 编译。已在本地周月报的保存配置中确认共享字段与原始数据集字段均显示名称。

公式输入框按来源高亮已识别引用：数据集字段蓝色 `#2563eb`、仪表板共享字段紫色 `#7c3aed`、日期参数青色 `#087f8c`。未识别、不完整及引号中的引用保持普通文字。使用原生 textarea 接收输入、选择与复制，同步的纯文本高亮层仅负责显示，不渲染公式 HTML。

回归覆盖三类引用、数据集隔离、字段改名、缺失引用、中文输入法组合期间不提前提交、换行及滚动同步；浏览器实测验证实际颜色、18 行公式内容完整和鼠标滚动后两层位置一致。无后端编译或数据库迁移要求。
