# 筛选器紧凑样式

与全局参数栏统一字号和控件比例，筛选器仍使用自己的配置和查询逻辑。名称不参与分组，按内容自然排列，不设固定列数。

旧内置默认值通过 `src/utils/queryAppearance.ts` 一次升级：标签 16 → 12px、控件文字 16 → 13px、高度 36 → 32px、单控件宽度 227 → 180px（日期区间沿用双倍宽度规则）、名称间距 8 → 6px、项间距 16 → 18px。同步调整默认文字和边框颜色、圆角及内部留白。宽度不足时整项换行，并约束控件不超出容器。

编辑器与渲染器共用迁移，`queryAppearanceVersion = 1` 标记完成。非旧默认值的颜色、字号、间距、宽高及纵向布局会保留。与旧默认值相同的手动设置无法与默认值区分，会一并升级；升级后再修改的设置不再覆盖。用户配置的查询、清空和重置按钮保留。没有按钮时不再渲染空按钮区域。

没有修改筛选值、日期边界、必填校验、联动、默认值、查询触发方式、全局参数批量应用与导出逻辑。

## 桌面仪表板缩小时的可读尺寸

筛选器根节点会跟随画布 zoom，全局参数栏不缩放。`readableQuerySize` 在桌面仪表板缩小时补偿标准字号、控件高度与宽度：内容至少保持 13px、标签至少 12px、控件至少 32px 高、单控件至少 150px 宽（区间按双倍规则）。如果用户明确设置了低于标准的紧凑尺寸，继续按原比例缩放。放大、移动端、iOS 与大屏保持原有比例。

补偿仅发生在渲染阶段，不改写配置；各筛选子控件通过注入的宽度函数计算显示宽度，继续引用原字段对象，避免影响选择值、联动和默认值更新。高度变化沿用已有内容高度观察和自动适配。浏览器对照验证：画布 100%/75%/50% 下输入文字约 13px、控件高度 32px，未发生水平溢出。

验证：`node tests/queryAppearance.test.cjs`、`node tests/dashboardParameterRuntime.test.cjs`；组件通过 Vue 模板、脚本和 Less 编译及 ESLint（原有未使用变量警告不在本次范围）。使用实际筛选器模板与 Element Plus 日期/单选/多选控件完成浏览器视觉检查、下拉选择与宽窄容器溢出检查；演示值未写入仪表板。
