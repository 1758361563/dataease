# 仪表板全局参数：第三阶段实施记录

日期：2026-10-12。状态：复制、模板/应用导入导出及参数查询隔离的代码适配完成，自动验证通过。运行服务尚未更新，真实业务口径验收尚未进行。

## 已实现

### 复制与版本

- 每份副本重新生成参数、共享字段及图表私有字段 ID，重写字段引用和字段别名；公共数据集字段继续引用原数据集。
- 已发布看板从正式版复制，编辑版与正式版的副本保持一致；未发布看板从编辑版复制。
- 卡片轴、筛选组件的选中卡片与字段映射、图表私有公式、联动及跳转配置同步重映射。复制关系图的正式版与编辑版使用相同的新 ID；跨看板的外部目标保留原关联，同看板自跳转跟随副本。
- 使用明确的 JSON ID 属性与公式引用替换，不再通过数字子串替换这些复制内容。名称、日期和公式字符串常量保持原值，兼容编码后的公式及 JSON 字符串列。

### 模板和应用

- DET2/DET2APP 导出携带参数与共享字段定义，以及计算字段绑定所需的原字段元数据和私有公式。定义同时进入模板样式的元数据，兼容现有内部模板存储入口；文件 DTO 增加独立配置属性。
- 导出清除会话参数值、查询时间基准和卡片上的临时定义覆盖。接收方使用自己的默认值和浏览会话。
- 导入重新生成参数、共享字段和私有字段 ID；实际模板解包入口已覆盖对象形式的动态卡片数据，参数引用、卡片引用和私有公式跟随新身份。
- 未绑定的样式模板沿用现有静态预览机制，依据文件中包含的字段元数据校验定义，不执行数据源 SQL。绑定到实际数据集后，进入正常的数据集和字段权限校验。
- 样式模板绑定按字段名称及兼容类型匹配，缺失或不兼容字段报错；同源且尚未绑定的模板卡片共同绑定到所选数据集。绑定前先计算所有映射，避免字段不匹配时部分修改画布。
- 应用导入会同步更新共享公式中的数据集与物理字段引用。含仪表板参数或私有字段的应用走现有通用数据集匹配入口，避免被仅支持物理字段的 V1 分支拒绝或改写成普通字段。
- 私有字段定义在导入保存时恢复到对应新卡片，不写入公共数据集；同一新卡片的重复保存不重复插入该字段。

### 查询、导出与缓存

- 单卡数据导出携带当前已生效的参数快照；待查询的草稿不会进入导出。
- 参数快照也写入现有图表扩展请求与最近一次查询记录，供仪表板批量导出的筛选请求传递。服务端参数绑定支持直接查询和扩展请求两种载体。
- 参数或共享字段参与的查询绕过现有结果缓存，因为旧缓存接口不包含仪表板定义及个人参数值。普通看板继续使用原缓存；本版没有新增通用参数缓存系统。
- 图表请求增加代次和参数上下文检查，迟到的旧查询结果不会覆盖新请求或新参数的结果。
- 模板准备读取正式版布局时不会覆盖编辑会话中的参数状态。

## 相对日期配置

新增默认值模式 RELATIVE，保存结构化 relative 对象：base（TODAY/YESTERDAY）、period（DAY/WEEK/MONTH/QUARTER/YEAR）、offset（-1200 到 1200 的整数）、position（START/END）。不翻译或改写已有宏。前端通过「当前/上一/下一/自定义偏移 + 周期 + 周初/月初/季初/年初或末尾」配置；默认基准今天，可在高级设置中改为昨天。日周期取当天，周一到周日为一周，季度按自然季度。预览按仪表板时区计算，后端在初始化时以同一参考时间解析所有参数。改变查询值与保存默认规则的生命周期保持原样。
