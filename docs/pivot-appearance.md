# 透视表：清透留白

本次只调整透视表的显示样式，不修改查询、排序、合并表头、对齐、总计和占比算法。

- 正文及行维度默认 14px，正文行高 38px，表头高度 40px。
- 默认正文及行维度使用常规字重，列头、角头和汇总文字使用 600 字重。
- 保留 `#F5F7FA` 浅色表头、`#FAFBFD` 行维度底色、`#EDF3FB` 汇总底色和 `#E9EDF3` 浅色网格。根据最新选择，正文采用石墨表头预览 B 的白色 / `#FBFCFE` 淡蓝灰隔行配色，不采用石墨色表头。
- 汇总的浅蓝底同时覆盖数据单元格与左侧汇总标签；自定义背景色、背景条件格式及合并占位单元格优先。
- 默认字体使用本地中文无衬线字体；仪表板指定字体时继续使用该字体。
- 沿用现有边框开关，升级内置样式时默认关闭纵向网格；用户之后可在样式配置中重新开启。

## 存量图表与手动配置

`pivotAppearance.ts` 在编辑器、存量渲染入口和新图表初始化入口执行同一套迁移，在画布缩放和列宽计算之前完成。

`basicStyle.pivotAppearanceVersion = 4` 标记迁移完成。仅替换缺省值及已知旧默认值；保留其他颜色、字号、行高、对齐及汇总配置。历史配置中显式设置为旧默认值与未修改过的默认值无法区分，这些值会一起升级。版本 1/2 升级仅补齐配色，不再次修改字号、行高、字重和边框开关；版本 3 升级仅恢复新版隔行色。显式关闭隔行底色和自定义隔行颜色继续保留。升级后，任何手动修改（包括重新设为旧默认值）都不会再被覆盖。编辑器展示的值和渲染使用的值一致；保存仪表板后会保存迁移结果。

编辑器会把十六进制默认底色保存为 `rgba(...)`。版本 3 按颜色值比较不透明 RGB/RGBA、三位/六位十六进制和带 FF 不透明通道的十六进制，修复此前旧灰底被误认为自定义配色而跳过的问题。半透明自定义颜色继续保留。已使用本地 15 张透视表保存配置，对旧版/版本 1/版本 2 共 45 个迁移用例验证；未更新数据库。

主题只修改透视表，不改变明细表等其他图形的全局默认配置。渲染阶段不再次缩放字号；S2 原有设备像素比机制保持不变。

## 验证

`node tests/pivotAppearance.test.cjs` 检查字符串/对象配置、存量升级、幂等性、手动配置保留、缩放字号、字体与字重以及编辑器/渲染入口连接。其余 `tests/pivot*.test.cjs` 覆盖多指标总计、汇总列宽、占比、表头顺序、日期格式及排序。

使用实际 S2 PivotSheet 和当前代码提取的主题方法进行了独立画布视觉检查；模拟数据未写入仪表板。编辑器和 S2 组件通过 Vue SFC 编译检查，修改文件通过 ESLint。前端更新生效，无需重新编译后端。
