# 数据集整页设计评审（2026-10-27）

用户已选择 C「专注筛选」，并授权实施。index.html 保留三个方向，便于追溯设计决策。

- A 分栏工作台：字段库、数据、右侧取值筛选并列。
- B 表格优先：全宽表格、条件标签、列头锚定筛选浮层。
- C 专注筛选：简洁主页面与字段 / 候选值 / 已选规则三栏工作区。

三个 design-*.html 均为自包含文件，无 CDN 依赖。包含示例数据和可操作交互：字段搜索、切换视图、独立滚动、候选值搜索、多选与排除、数值及日期范围、筛选列、分页、完整值查看、CSV 下载。Excel 只演示入口，不生成伪文件。

约束：预览筛选及筛选列仅影响当前查看和本页导出，不写入数据集定义，不改变卡片数据范围。搜索固定在滚动区之外，表格、字段列表、候选列表分别滚动。

本目录保留评审时的示例原型；正式页面按 C 方向实施，并保留现有字段类型修改等管理能力。实施和验证记录见 ../../docs/dataset-preview-improvement-plan.md 第11节。原型维护源及生成器位于工作区 .companybi-prep/dataset-design-authoring。
