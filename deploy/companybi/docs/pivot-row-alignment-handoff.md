# 透视表维度行头真实定位与24/28/32px密度修复

日期：2026-11-05。本地修改，未Commit、Push或部署。应与当前工作区的筛选窗口、表格样式等改动一起构建；无后端、数据库迁移或环境变化。

## 根因及修复

前轮仅检查了数值区实际坐标和主题的middle配置，未覆盖S2维度行头的真实定位。S2的BaseRowCell/RowCell使用getAdjustPosition，返回的是文字框顶部，并会在视口边缘调整位置以尽量让文字完整可见。把基线改为middle而没有换算Y，导致完整行偏上半个字号；部分行还会因边缘调整而与数值不同步。

项目内PivotAppearanceRowCell现在覆盖实际定位：

- 普通叶子维度及单行组标签使用单元格内容区中心，底部/顶部被截断时保持本行中心，与数值区一致自然裁切，不把标签挪向相邻行。
- 跨多行合并维度保留S2随可见区调整的能力，将引擎返回的顶部坐标加半个字号转换为middle坐标，避免大分组标签不可见。
- 展开/收起及操作图标同步以同一中心定位，横向对齐不变。修改项目行头类，不修改node_modules引擎。

密度改为紧凑24px、标准28px、舒适32px，新建默认标准28px。缩放保护的额外行高空间从18px改为8px，避免小档位被最小行高覆盖；大字号仍允许必要的高度以免裁字。

样式版本3将版本2的旧预设32/40/48px分别迁移为24/28/32px，仅在行高/表头仍匹配旧预设时转换；保留自定义高度和颜色。版本1亦可升级。选择配色继续保留所选密度。
