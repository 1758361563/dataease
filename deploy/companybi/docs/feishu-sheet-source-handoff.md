# 飞书表格接入：代码交付与验收交接

日期：2026-11-02

## 页面操作链路

1. 数据源 → 添加 → 飞书电子表格；或进入 MySQL 数据源，在表列表 / 数据更新中选择“接入飞书表格”。
2. 在三步侧栏向导中选择已配置的飞书应用连接，填写 Sheets URL，加载工作表，设置表头、数据起止行与列范围。
3. 选择已有 MySQL 数据源和目标表。新表可手写 CREATE TABLE 与索引 SQL，复用原有建表检查、幂等执行及异常核查能力。
4. 配置源字段到目标字段的映射、必填规则、日期格式及显式空值标记（例如 None）。预览最多 15 行并检查目标结构及转换规则。
5. 保存后可立即同步，也可设置每日时间与时区、上游成功触发，或加入已有任务组安排下游 SQL。任务组内任务由组统一调度。
6. 表列表标注飞书来源。数据更新展示最近结果、最近成功时间、下一计划及超期状态；向导内可查询历史、取消运行及核查异常占用。

## 执行与数据语义

- 飞书应用凭据继续由集成连接管理；Node 内部执行器只读飞书，通过私有进程通信返回分页数据。Java 使用所选 DataEase 数据源连接写目标库。
- 配置继续存放在 company_feishu_source，新增 managed_task_id、target_datasource_id、source_json、data_end_row；更新任务保存不可变配置版本。旧 enabled / schedule_json 在接管后关闭，计划统一由数据更新执行。
- 每次同步为全量快照。先写 MySQL TEMPORARY staging table，严格验证字段类型、主键唯一性、最小行数和空结果策略，再用同一 InnoDB 事务 DELETE + INSERT 发布；失败回滚保留旧数据。目标表索引及授权保留。
- 目标必须是明确配置数据库名称的 MySQL 数据源及 InnoDB 实表，不接受含触发器或被外键引用的目标。
- 小数超出目标精度、整数截断、非法日期、字段缺失等会阻断；不会自动将 17.798595 四舍五入成整数。None 只在显式配置为空值时转换。
- 每页最多 100 行，最多 256 列，任务读取上限可配置、最高 100 万行。预览为样本校验，正式运行校验全量。界面工作表行数是网格范围，不代表有效数据行数。
- 飞书分页读取不提供跨请求一致性快照。实现检查读取期间表头及网格行数变化；同一范围内的并发单元格编辑无法全部检测，正式计划应避开集中编辑时段。
- 支持 feishu.cn 的 /sheets/ 地址；Lark、wiki、多维表格、附件不在本轮范围。读取单元格结果，不迁移公式定义。
- 手动、定时、依赖及任务组复用已有占用保护。提交断连、执行锁丢失或进程中断进入待核查，保留持久占用；用户核查快照、确认旧执行结束后解除。不自动重放结果未知的同步。
- 删除同步任务保留物理表，解除来源与任务绑定；现有下游依赖和任务组检查继续生效。

## 历史来源接管

向导读取未绑定任务的 company_feishu_source 记录。接管前须在旧执行器停用来源（enabled=0），并确认在途运行结束；页面再次确认后绑定原来源 ID 和原库表。服务端拒绝仍启用的旧来源及重复绑定。接管必须重新选择应用和字段映射、预览；不会自动启用调度或同步四张历史表。

external_inputs.json 保留迁移映射，不参与日常同步配置。成功运行会同步更新 company_feishu_source.latest_success_at；运行历史及新鲜度以统一任务记录为准。

## 交付与验收

前端、Java 后端、feishu-integration worker 源码须一起构建部署。后端启动幂等添加配置列。启用执行需要稳定的 COMPANY_BI_INSTANCE_ID，以及已有集成连接的加密密钥与飞书读取授权。

本轮仅做 Java 编译与单元测试、Node 纯函数测试、Vue 脚本 / 模板 / 样式编译及 API 请求契约检查、静态 lint。未执行全量构建、启动服务、连接数据库、调用飞书或部署。
