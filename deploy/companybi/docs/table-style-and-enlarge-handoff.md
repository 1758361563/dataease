# 表格样式与放大视图更新交接

日期：2026-11-05。基于本地HEAD `d308d0fdd8` 修改；本轮未Commit、Push或部署。仅前端变更，按现有简化更新流程构建发布，无数据库迁移、新环境变量或服务。

## 已实现

- 透视表、明细表、汇总表统一默认“清爽浅色”：浅灰表头、白色/浅色交替行、15px深色文字与淡色1px横纵分隔线。默认行高、表头高度28px。新建默认值及编辑/渲染初始化使用同一套样式。
- 新建、迁移和旧表在首次加载时统一到该默认；`basicStyle.tableStyleVersion=3`后不再覆盖后续手动设置。Version 1仅替换仍为旧方案值的颜色/字号/行高，保留自定义颜色及已关闭的分隔线。此次按用户要求统一存量表格配色，不执行数据库批量修改，编辑保存时随图表配置持久化。
- 单图表编辑“样式 → 表格样式方案 → 配色方案”可选清爽浅色、靛蓝表头、深色表头。选择方案同时设置表头、行头、数据区、字体大小、行高、分隔线；保留数据字段、日期分组、格式化规则、条件格式及总计/小计配置。手动改色后显示“自定义（当前设置）”，仍可选择预设恢复。
- 同区域新增“表格疏密”：紧凑24px、标准28px、舒适32px；切换配色保留已选密度，手动设置其他行高显示“自定义行高”。
- 查看页图表菜单的“放大”默认铺满浏览器视口，右上角图标可切换全屏与窗口模式，窗口占视口宽高80%；每次重新打开放大均默认全屏。详情窗口保留原打开方式，关闭及ESC沿用现有弹窗行为。
- 去掉放大模式70vw/65vh的内容限制，内容区按剩余高度布局。表格在弹窗尺寸变化时从缓存数据重建，重新计算表头、列宽与冻结区，不重新查询业务库。导出分辨率设置及图片导出功能保留。
- 切换按钮使用原生透明按钮和内联线框SVG，背景透明、无边框/胶囊/阴影；SVG及其路径强制fill:none，避免窗口状态变成黑色实心块，保留键盘焦点和无障碍名称。
- 表格在画布缩放后仅对渲染副本处理：字号取整且最低13px，行高按字号预留空间，使用Segoe UI/微软雅黑UI字体栈，避免15px被缩成过小的小数字号。原保存的字号和密度不被渲染过程改写。

## 设计参考与二轮验证

参考[Carbon表格规范](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/specifications)的字号/行高分离、32/40/48px密度档位，以及[Ant Design Table](https://ant.design/components/table/)的尺寸和边框配置方式。本项目保留透视表竖线，采用更淡的边框与更深的文字，配色为本项目适配，不是直接复制参考产品。

二轮Chrome检查使用真实AntV S2 Canvas与实际主题构造器生成的主题，合成16行数据。全屏、窗口、切回全屏三个状态中，按钮背景均为rgba(0,0,0,0)、边框0px、阴影none、图标fill为none；正常显示线框。截图为`.companybi-prep/table-ui-probe/fullscreen-v2.png`，布局报告为dom-v2.html，均不进Git。

后续修正：疏密在小比例画布上曾被最小行高合并，现按原始配置保持32/40/48px三档；所有文字变体统一垂直居中。最新验证与筛选窗口改动见filter-ui-and-table-density-handoff.md，后续发布应一并包含。

最新修正：实际维度行头需换算S2的文字顶部坐标，且普通行不再参与边缘可见区挪动；新密度为24/28/32px，默认标准28px，32项回归及实际行头Canvas验证通过。详见pivot-row-alignment-handoff.md，发布须一并包含。
