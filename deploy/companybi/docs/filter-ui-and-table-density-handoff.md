# 图表筛选窗口、表格疏密及垂直对齐修复

日期：2026-11-05。本地修改，未Commit、Push或部署。与当前工作区的表格样式/放大改动一起构建发布；仅前端，无数据库迁移、环境变量或服务变化。

## 筛选窗口

- 原筛选值弹层固定`top-start`，双栏面板高度大，容易跑出视口。字段输入还会在输入时恢复旧字段名，值输入为readonly，只能再点弹层内搜索框。
- 重构图表筛选专用的`filter/auth-tree-chart`组件，不修改数据集权限过滤器。字段与枚举值均使用可直接输入的filterable选择器；弹层优先向下、空间不足自动翻转，采用视口边界约束及有限列表高度。
- 条件组采用独立卡片及关系选择器。新建/空筛选与新增子组默认AND；已有有效OR、嵌套关系保持，修改一个组不再自动翻转其他组。字段、操作符、数值、固定/动态日期及最终表达式API结构沿用现有实现。
- 保留多选、当前搜索结果全选、清空、已选标签与批量输入；枚举值也可直接输入后回车添加。等于/不等于限制为单值，空/非空不需要值。保留0、false、空字符串等非null枚举值，快速切字段时忽略旧请求结果，加载失败可重试或手动输入。
- 窗口高度随内容，长列表只滚动内容区，底部操作区可见。编辑使用独立草稿，取消/ESC关闭不会改动保存的图表条件。

## 表格疏密与上下居中

- 疏密失效根因：画布缩放把32/40/48px分别缩小，随后最小字号与行高保护把它们压到相同或相近高度。现在根据原始配置识别明确选择的密度，在缩小仪表板时仍保留32/40/48px屏幕行高；放大时继续放大，手动自定义行高不被强制当作预设。
- 垂直偏上根因：旧逻辑只修改普通rowCell.text，S2加粗/指标名/序号等变体及数据区仍可能使用top基线。共享表格主题与透视表覆盖层统一所有文字变体为middle，横向对齐设置保持。
- `normalizeTableReadability`只处理渲染副本，并接收原始图表与缩放比例；保存的字号、行高和条件配置不被显示缩放改写。
