# 帕累托图

入口：图表类型 → 柱状图分类 → 帕累托图。一个类别维度、一个数值指标；支持过滤、额外工具提示字段以及维度联动/跳转。

柱形按聚合指标降序，折线表示筛选后全部类别的累计占比，右轴固定 0–100%。默认 80% 参考线；基础样式可设置累计线颜色、参考线开关与比例、柱形数值和占比标签，沿用柱宽、颜色、图例、坐标轴和标题设置。

后台查询最多取 5001 个聚合类别，超过 5000 时明确报错，要求缩小筛选范围；不将截断结果当作完整分母。其他图表切入时的结果条数不影响口径。负值拒绝，空值按零；全零时累计占比无定义，折线不显示。指标快速计算不支持叠加到此图，累计占比由图表生成。

累计占比是图表渲染的派生值，现有数据导出沿用原始聚合字段；图片导出沿用通用图表导出。
