## 1. 已确认的产品边界

**筛选数据与筛选列都是预览功能，只影响当前页面查看的数据，以及从该页面发起的 CSV / Excel 导出。它们不改变数据集本身，不影响任何卡片、仪表板或其他用户的查询。**

具体约定：

- 筛选数据决定此次查询返回哪些行；筛选列决定此次预览和导出显示哪些列。
- 数据集保存不携带预览筛选、预览列选择、搜索词、分页或临时列宽；隐藏列不删除字段。
- 预览设置保存在当前工作区的前端内存中。同一数据集内切换视图时保留；关闭页面、刷新浏览器或切换数据集后重置。暂不增加个人偏好表或服务器持久化。
- 修改名称、来源、SQL、关联、字段定义仍属于原有数据集编辑操作，只有这些修改进入保存流程。
- 导出使用点击导出时的条件和列选择；随后调整预览不会改变已提交的导出任务。
- 本轮不增加“数据集固定过滤条件”，不修改卡片筛选语义，不复制观远与本需求无关的标签和功能。

## 2. 本轮范围与页面组织

### 查看数据集

保留资源目录和数据集基本信息，将主要工作区明确为：

1. **数据结构**：字段显示名、原始字段名、类型，以及已有的公式等信息；提供字段搜索和现有编辑入口。
2. **数据明细**：分页预览表格；工具栏集中放置“筛选”下拉入口、“导出”下拉入口和刷新。现有计算字段及批量管理入口在具备编辑权限的位置保留。

“筛选”下拉包含“筛选数据”和“筛选列”；“导出”下拉包含“CSV”和“Excel”。界面名称可在实现时微调，但功能和作用范围保持一致。

### 编辑数据集

- 保留同一个编辑工作区，提供“数据建模”和“字段与预览”两个主要视图。
- “数据建模”负责单源/跨源、数据源与表搜索、实体表、自定义 SQL、关联关系。
- “字段与预览”承载数据结构/批量管理与数据明细，复用查看页的预览、筛选及表格能力。
- 数据源侧栏只在建模视图占空间；字段侧栏可以收起，不和数据源侧栏长期叠加挤压表格。
- 保存、保存并返回、离开未保存提醒沿用原流程；切换视图不自动保存。
- 复用现有设计变量、导航和目录风格，检查顶部工具栏、资源树、保存/移动等实际存在的目录入口。此处仅做展示统一，不改变目录和权限语义。

## 3. 预览筛选交互

### 筛选数据

- 打开规则面板，支持新增、修改、删除规则，以及全部清空。
- 多规则可选“全部满足（AND）”或“任一满足（OR）”；优先复用现有条件树的数据格式与查询转换，不另造规则语言。
- 第一版界面以平铺规则为主，不主动增加多层嵌套规则编辑器。
- 文本支持值选择、候选值搜索、批量粘贴、包含/排除，以及等于、包含等适合文本的条件。
- 数值支持比较和范围；日期支持指定日期和范围；提供适用的为空、不为空等条件。
- 根据字段类型提供默认编辑方式，不照搬截图中语义尚不明确的“自动”选项。
- 批量粘贴按行拆分，去重并保留字符串含义；数字、日期做类型校验，不能把无效输入静默丢弃。
- NULL 与空字符串分别处理；范围边界的包含关系要明确；时间沿用 BI 现有时区和日期规则。
- 面板内编辑有独立临时值，点击“应用”才更新查询；取消不改变当前条件。
- 应用后回到第一页并重新查询，在工具栏显示已应用条件数量，提供清除入口。

### 候选值

- 从后端查询字段值，不能从当前预览页或前 100 行推断完整候选值。
- 支持服务端搜索与分批加载；第一版候选值按当前数据集/草稿及权限取值，不额外实现规则之间的级联候选过滤。
- 已选值独立保存，翻页或搜索不丢选择；候选列表中的“全选”明确为当前已加载结果，不能伪装成全部数据库值。
- 已保存数据集复用现有枚举查询；编辑草稿需要让枚举查询使用同一份草稿。新增字段也应能够筛选。

### 筛选列与字段搜索

- 筛选列提供搜索、全选、逐项勾选和已选数量；确认后影响当前表格与导出。
- 至少保留一列；默认选中当前允许查看的全部输出字段，顺序沿用字段顺序。第一版不增加列重排功能。
- 字段搜索匹配显示名和原始名，只过滤列表展示；不修改完整字段数组，不影响数据集保存。
- 搜索后“全选/取消全选”仅作用于匹配项，并明确其范围；搜索之外的选择继续保留。
- 隐藏列可以继续参与筛选和计算；选中列集合与计算所需完整字段集合必须分开。
- 来源变化时按字段 ID 保留仍有效的选择。字段消失或类型改变导致规则无效时，提示修复并暂停相关查询/导出，不能自动忽略规则后展示更大范围的数据。

## 4. 预览查询与表格

- 筛选在后端执行，然后再分页；不能只对前端已加载的样本过滤。
- 默认每页 100 行，提供常用页大小并设置服务端上限，不做全量浏览器加载。
- 行数统计使用与预览一致的来源、条件和权限；统计未完成时显示“统计中”，失败时显示不可用，不用样本行数代替总数。
- 页面查询、统计和枚举查询都使用请求序号/草稿版本校验；旧请求的响应不得覆盖新状态。可取消的请求同时取消。
- 来源、SQL、关联或字段定义变化后标记旧结果失效；字段结构更新完成后才能刷新。尚未应用的 SQL 编辑内容不能被误认为已参与预览。
- 翻页使用一致的排序策略；存在可用唯一键时尽量形成稳定顺序。数据库在翻页期间发生变化时不承诺跨请求快照一致性，本轮不引入数据库快照系统。
- 表格提供合理最小列宽、列宽拖拽、可达的横向滚动条、固定表头及完整值查看/复制；长文本允许打开单元格详情。
- 移除没有业务依据的“固定最后一列”；列名、字段类型、NULL、空字符串和长数值应能辨认。
- 查看页和编辑页共用表格及预览交互，避免两套独立行为。

## 5. CSV / Excel 导出

- 默认导出当前条件下的全部匹配行和当前选中列，列顺序与预览一致；不是只导出当前页。
- 复用已有导出中心、任务进度、失败提示和下载流程，补充格式选择及 CSV 写出，不另建导出系统。
- 沿用现有可配置导出上限；超出时明确提示实际限制，不能把截断结果标为完整导出。
- 已保存数据集按 ID 加预览条件、列 ID 和格式发起导出；未保存编辑草稿按点击时的完整草稿发起导出，无需先保存数据集。
- 草稿只作为该导出任务的输入，使用现有任务参数存储，不写入数据集定义。任务提交后保留输入快照，避免执行时重新读取已被修改的定义。
- 前端不能提交任意拼接查询作为可信最终 SQL；后端根据合法字段、条件、来源和现有 SQL 编辑权限组装并校验查询。
- “一致”指查询条件、列选择和草稿定义一致；源数据库后续变化可能使导出值与早先预览不同，本轮不冻结业务数据库。
- CSV 使用适合中文 Excel 打开的 UTF-8 编码（含 BOM），正确转义逗号、引号和换行；处理文本被表格软件当公式执行的问题。
- Excel 保留适当的数据类型，长整数/编号避免精度丢失；超过单工作表容量沿用现有拆分能力或明确提示。
- 下载扩展名、响应类型、任务文件路径和重试流程均按真实格式处理，不能只把 xlsx 改名为 csv。
- 预览、枚举、总数及导出按相同访问范围执行；导出继续遵守导出权限、行列权限及脱敏规则。

- `core/core-frontend/src/views/visualized/data/dataset/form/index.vue`：编辑草稿、字段集合、上下建模/预览布局、保存与预览请求。

- `core/core-frontend/src/views/chart/components/editor/filter/auth-tree/`：现有规则和枚举交互可复用的线索；提取必要能力时避免改坏图表筛选和权限编辑。
- `core/core-frontend/src/api/dataset.ts`：预览、枚举和导出 API。
- `DatasetDataServer.previewData()` 和 `DatasetGroupManage` 的已保存预览当前限制为前 100 行。
- `DatasetDataManage.previewDataWithLimit()`：已有查询、字段转换、权限及分页 SQL 生成基础，需要接入预览条件与列投影。
- `DatasetGroupInfoDTO` 当前没有预览筛选/列选择字段；新增专用于查询的请求结构，避免把临时参数混入保存模型。

- `ExportCenterManage` / `ExportCenterDownLoadManage`：现有任务和 XLSX 写出；文件扩展名目前多处固定为 `.xlsx`，需同步调整。
- `CompanyDatasetDesignFilter` 及现有资源权限检查：新增接口必须纳入相应权限控制。

前端状态分为两部分即可：数据集编辑草稿，以及当前页面预览状态。查询时生成输入快照；预览、统计、枚举和导出共用必要的条件校验与查询组装，避免出现各自解释规则的情况。

建模组件先保持挂载，通过显示切换保留节点与未确认编辑状态；恢复显示后进行尺寸重算。仅提取实际需要共享的状态，不一次性重写整个建模编辑器。

## 8. 验收重点

1. 在超过 100 行的测试数据中筛选仅存在于后续行的值，仍能查出；总数、翻页和导出结果一致。
2. 覆盖文本选择/排除/批量粘贴、数值范围、日期、NULL、空字符串，以及 AND / OR。
3. 取消筛选面板不改变结果；应用后重置页码；清空后恢复；搜索候选值不丢已选值。
4. 隐藏列只影响当前预览和导出；隐藏列仍可参与筛选；字段搜索和列选择不缩减保存内容。
5. 设置筛选后保存数据集、重新打开、查看原有卡片，确认数据集定义与卡片查询范围未因预览设置改变。
6. 建模和预览往返切换，节点、SQL、关联、计算字段及未保存修改均保持；画布和表格尺寸恢复正常。
7. 连续改 SQL/来源并刷新，旧请求不能覆盖新结果；无效字段引用有明确提示，不能静默放宽查询。
8. 单源、跨源、多表关联、自定义 SQL、计算字段/分组字段均覆盖；未保存草稿的预览和导出使用同一份定义。
9. CSV / Excel 覆盖中文、引号、逗号、换行、长编号、空值及多页数据；导出上限、任务失败和重试正确反馈。
10. 不同权限账号下，候选值、统计、预览和导出均不扩大原有可访问范围。
11. 常用桌面尺寸和缩放下，长字段名、大量列、空结果、侧栏折叠与横向滚动均可用。

## 10. 2026-10-27：聚合计算字段引发的预览排序回归

- 用户在“月产品销售表”发现 `Expression #26 of ORDER BY contains aggregate function and applies to the result of a non-aggregated query`。
- 原因：本轮新增默认分页排序时，对全部字段重新展开计算表达式。原有明细投影将聚合字段显示为占位值（`-`），排序却重新插入了 `SUM(...)`，导致非聚合明细查询被数据库拒绝；统计查询也错误地保留了排序。此前测试只覆盖普通计算字段，遗漏了此场景。
- 修复：预览排序使用已生成的输出列别名，不重新展开公式；统计查询完全不生成排序。显式排序方向归一为 `asc/desc`。保持既有聚合字段的明细占位行为，不修改数据集定义和卡片聚合逻辑。
